# OpenCV Homework 1

Basic Computer Vision - Homework 1

This repository contains the implementation of CLAHE (Contrast Limited Adaptive Histogram Equalization) using OpenCV.

## Contents

- `BCV_CLAHE_Homework.ipynb` - Jupyter Notebook containing the implementation and development process
- `Norway.jpg` - Input image used for testing

## Exercises

- Exercise 1: Noninteractive CLAHE pipeline with command-line parameters
- Exercise 2: Interactive CLAHE pipeline using OpenCV Trackbars
